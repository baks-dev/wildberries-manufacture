# Wildberries Manufacture - Анализ проекта

## Краткое резюме
Этот проект представляет собой Symfony Bundle, который интегрируется с API Wildberries для управления производством заказов и инвентарем. Он предоставляет комплексную функциональность для моделей складов FBO (Full Warehouse Operator) и FBS (Fulfillment by Seller).

## Ключевые компоненты

1. **Слой интеграции API**
   - Интеграция с API заказов с поддержкой пагинации
   - API для управления остатками FBO
   - API для информации о складах FBS
   - Функциональность обновления остатков FBS (временно отключена)

2. **Слой обработки данных**
   - Реализация Message bus для асинхронной обработки
   - Паттерн репозитория для доступа к данным (ORM и DBAL)
   - CLI команды для ручного получения данных

3. **Пользовательский интерфейс**
   - Админ-контроллеры для задач производства FBS
   - Админ-контроллеры для управления инвентарем FBO

4. **Автоматизация**
   - Периодические задачи для регулярной синхронизации данных
   - Роли безопасности и контроль доступа

## Архитектурные паттерны

- **Паттерн UseCase**: DTO + Handler для бизнес-логики
- **Message Bus**: Symfony Messenger для асинхронной обработки
- **Паттерн Repository**: ORM и DBAL для доступа к данным
- **Паттерн Scheduler**: Symfony Scheduler для периодических задач
- **Dependency Injection**: PSR-11 с автовнедрением

## Технические преимущества

- Четкое разделение ответственности
- Хорошо задокументированный кодbase с CLAUDE.md
- Современная архитектура Symfony
