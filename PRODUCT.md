# Wildberries Manufacture - Продуктовая спецификация

## Обзор

Wildberries Manufacture - это Symfony Bundle, предназначенный для интеграции с API Wildberries для управления производственными процессами по заказам и остаткам товаров.

## Цель

Цель проекта - предоставить инструменты для автоматизации получения данных о заказах и остатках Wildberries, а также управления производственными процессами на основе этих данных.

## Функциональные возможности

### 1. Получение данных о заказах
- Синхронизация заказов с API Wildberries
- Поддержка пагинации для обработки больших объемов данных
- Кэширование ответов API для оптимизации производительности
- Обработка блокировок API (HTTP 429)

### 2. Управление остатками
- Получение остатков на складах (FBO)
- Обновление FBS-остатков
- Поддержка разных типов складов (FBO и FBS)

### 3. CLI команды
- Команда получения последних заказов за определенный период
- Команды обновления остатков FBO и FBS
- Интерактивный выбор профилей пользователей

### 4. Админ-интерфейс
- Просмотр списка сборочных заданий FBS
- Просмотр товаров для пополнения FBO

### 5. Асинхронная обработка
- Использование Symfony Messenger для асинхронной обработки данных
- Отдельные транспорты для каждого профиля пользователя

### 6. Планирование задач
- Периодическое обновление заказов (каждые 3 часа)
- Периодическое обновление остатков (каждые 3 часа)
- Ежедневное обновление FBS-остатков
- Ежедневная очистка старых заказов

## Целевая аудитория

- Пользователи, работающие с данными о заказах и остатках Wildberries
- Системные администраторы, управляющие производственными процессами
- Разработчики, интегрирующие данные с другими системами

## Уникальные особенности

1. Поддержка нескольких профилей пользователей с изолированными данными
2. Асинхронная обработка через Symfony Messenger
3. Полная интеграция с Symfony Scheduler
4. Поддержка разных типов складов (FBO и FBS)
5. Система кэширования для оптимизации взаимодействия с API

## Взаимодействие с другими системами

- Интеграция с API Wildberries
- Поддержка Symfony Framework
- Работа с Doctrine ORM/DBAL
- Совместимость с другими модулями BaksDev

## Безопасность

- Защита API ключей через переменные окружения
- Роли и Voter для контроля доступа к функциональности
- CSRF защита для форм
- Экранирование данных в интерфейсе
- Журнал аудита для событий безопасности
