# План развития: Модуль Wildberries Manufacture

## Обзор
Этот план развития описывает запланированную разработку и улучшение Symfony Bundle для Wildberries. Модуль обеспечивает интеграцию с API Wildberries для управления заказами и инвентарем.

## Фаза 1: Основа (Текущее состояние)
### Завершено
- Основная интеграция API для заказов и остатков
- Структура сущностей для заказов и инвентаря
- CLI команды для получения данных
- Админ-интерфейсы для управления FBS и FBO
- Реализация Message bus для асинхронной обработки
- Планировщик задач для периодических операций
- Система безопасности с управлением доступом по ролям

### В работе
- Функциональность обновления остатков FBS (временно отключена)
- Комплексное тестирование
